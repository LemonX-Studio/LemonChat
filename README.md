# 🍋 Lemon Chat

> 一款个人独立开发的安卓原生即时通讯 APP——**白 + 绿清爽配色、全圆角、悬浮毛玻璃底部导航**，不一般的小众聊天软件。

**🚧 状态：内测中，尚未正式发布（Not Released Yet）。** 仓库已公开用于代码展示与进度追踪，Release / 可安装的 APK 将在完成整体测试后放出。当前版本 v0.4.4。

---

## 这是什么？

简单说：**Lemon Chat 是一个可以自己搭的"微信"。**

它不是套壳网页，而是用 Kotlin + Jetpack Compose 写的**安卓原生 APP**。加好友、私聊、群聊、拉黑一应俱全，还有一个别家没有的杀手锏：**群中群（套娃群）**——可以在一个团队里像真实公司一样搭出「部门」和「小组」的组织架构。

后端跑在 Cloudflare Workers 全球边缘网络上，数据存在 Neon 云端 PostgreSQL，**全免费架构，零服务器费用**。

## ✨ 功能亮点

### 账号
- 注册/登录：用户名 + 密码，**无需手机号、无需实名、无需邮箱**
- 密保问题自助找回密码
- 昵称 / 签名 / 头像（上传自动压缩，CDN 分发）
- 管理员封禁体系（临时封 / 永久封 / 解封，专属封禁提示页）

### 好友与私聊
- 搜索加好友，**申请制**（对方同意才算加上）
- 删好友 / 拉黑 / 黑名单管理
- 实时消息提醒（WebSocket 长连接 + 轮询双保险）

### 群聊
- 独立数字群号，搜群号加群
- 进群申请队列，群主逐个审批；可开关「自由加入」
- 群主管理面板：审批 / 邀请 / 退群 / 解散

### 群中群 · 组织架构（最大特色 ⭐）
- 群可以套娃：**团队 → 部门 → 小组**，最多 3 层
- 专属编号系统：`0-t1`、`1-d2`、`3-g5`（t=临时 d=部门 g=小组）
- 团队结构树可视化，层层展开、点谁进谁的群
- 层级返回导航：小群 → 上级群 → 团队页，系统返回键逐层退出
- 临时群：1~180 天有效期，到期自动清理

### 媒体消息
- 图片消息：全屏预览、双指缩放、长按选择保存
- 视频消息（≤8MB）：全屏播放、滑动切换、长按选择保存
- 聊天内多图/多视频支持左右滑动连续查看

### 管理后台
- 用户管理（注册信息）、实时在线列表
- 封禁 / 解封 / 强制下线 / 群管理

## 🏗️ 技术架构

| 层级 | 技术 |
|------|------|
| 客户端 | Kotlin + Jetpack Compose（安卓原生，minSdk 26 / Android 8.0+） |
| 实时通信 | WebSocket（Cloudflare Durable Objects 有状态长连接） |
| 服务端 | Cloudflare Workers（Serverless 边缘计算） |
| 数据库 | Neon 云端 PostgreSQL（HTTP 驱动直连） |
| CI/CD | GitHub Actions 自动构建 APK |
| 签名 | 自有 JKS 签名 |

## 📁 目录结构

```
android/                安卓客户端（Kotlin + Compose）
  app/src/main/java/com/lemon/chat/
    MainActivity.kt     主界面 + 聊天逻辑
    ui/                 自定义组件
.github/workflows/      Actions 自动构建
backend/                后端（Cloudflare Workers）
```
